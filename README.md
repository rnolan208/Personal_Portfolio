## Key Features

- **Interactive Home Hero**
  - Click-through visual narrative representing my journey into software development
  - Dynamic text with imagery
  - Light → dark mode transition tied to progression on the final image

- **Projects Showcase**
  - Project cards with:
    - Image slideshows (with captions, arrows, pause-on-hover)
    - Overview of project
    - Tech stack icons
    - Links to external platforms -> GitHub, LinkedIn, YouTube
    - Embedded demo videos

- **Responsive Design**
  - Mobile-first layouts
  - Optimised hero section for smaller screens (mobile / tablet)
  - Fixed navbar with scroll-based shadow
  - “Back to Top” button

- **Accessibility & UX**
  - Semantic HTML
  - ARIA labels
  - Tooltips for social icons
  - Keyboard- and touch-friendly interactions

## How to Run

To run this project locally:

### Clone the repository
``` bash
git clone https://github.com/rnolan208/Personal_Portfolio
```

### Navigate into the project folder
``` bash
cd Personal_Portfolio
```

### Open in browser
Start index.html in preferred browser
