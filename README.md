# Robert Nolan – Developer Portfolio

This is a website for my personal portfolio, showing my university and personal projects.
It outlines my move from architecture to software development, highlighting projects, skills, and design-focused thinking.

The website is hosted on netlify and is available at https://robertnolan-portfolio.netlify.app/
*(auto-deployed via GitHub + Netlify)*


## ** File structure **

- index.html
- about.html
- contact.html
- projects.html
- skills.html
- script.js
- style.css

## ** Tech Stack **
- **FrontEnd**
  - HTML5
  - CSS3 (Flexbox, Grid, Media Queries)
  - JavaScript (Vanilla)

  - Font Awesome (icons)

---


## ** Features **
- **Interactive Home Hero**
  - Click-through visual narrative representing my journey into software development
  - Dynamic text with imagery
  - Light → dark mode transition tied to progression on the final image

- **Projects Showcase**
  - Project cards with:
    - Image slideshows (with captions, arrows, pause-on-hover)
    - Overview of project
    - Tech stack icons
    - Links to external sites -> Github, LinkedIn, YouTube
    - Embedded demo videos

- **Responsive Design**
  - Mobile-first layouts
  - Optimised hero layout for smaller screens (mobile / tablet)
  - Fixed navbar with scroll-based shadow
  - “Back to Top” button

- **Accessibility & UX**
  - Semantic HTML
  - ARIA labels
  - Tooltips for social icons
  - Keyboard- and touch-friendly interactions
